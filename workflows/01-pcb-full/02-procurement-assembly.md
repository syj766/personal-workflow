# 02 · 采购与装配（SOP）

> 版本：v1.0

**PCB 采购与焊接标准流程（SOP）**

1. **定稿导出**：PCB 定稿，确认所有贴片件的封装、极性、参数无误，导出 BOM 清单和坐标文件（坐标覆盖全部贴片件）。
2. **BOM 审核与匹配**：核对型号、封装、极性、参数；在嘉立创完成元件匹配，**优先基础库、BOM 带商品编号（C 编号）、自助匹配**（免人工匹配费），扩展库料（20 元 / 种）尽量少。
3. **焊接方式决策**：
   - 无密脚 IC、贴片件约 < 10–20 个、预计手焊 < 半小时 → 贴片件全部自行焊接；
   - 有 QFN/DFN/TSSOP/QFP/BGA 等密脚 IC，或贴片件多、预计 > 半小时 → 走 PCBA，**可贴列表内元件一次性全贴，不留小件手焊**。
4. **PCBA 下单**：同一版次的多片板全部放进**同一个 SMT 订单**（工程费按单收 50 元、焊点 1 分 / 个、钢网免费，切勿拆成多单）；核对完整报价（工程费 + 焊点费 + 换料费 + 器件费）后确认，通常一次 5 片起。
5. **大件采购**：电池座、排针、按键、连接器等，**受力 / 反复插拔件优先选插件封装**；按价格与供货可靠性在淘宝 / 立创选择，标准小件立创顺带下单，模块或立创缺件淘宝；高频通用、不易贬值的元件（常用阻容、三极管、二极管、排针、按键）适度备货，**IC 类不囤**。
6. **到货检查与上电**：先目视检查，**万用表测电源对地无短路**；再完成焊接 / 检查，分级上电（先电源、后整机）并做功能验证。
7. **记录与沉淀**：将实际采购型号、成本、故障 / 返工记录存入对应项目；更新 EDA 常用元器件库（含 C 编号、封装、是否基础库）和实物库存。
